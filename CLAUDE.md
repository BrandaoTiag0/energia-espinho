# Projeto: previsão de consumo elétrico de Espinho (v1)

Objetivo: prever o consumo mensal de eletricidade de Espinho com dados abertos da E-Redes.

Sucesso: o modelo tem de bater a previsão simples "igual ao mesmo mês do ano anterior".

Regras:
- Gastar zero dinheiro (Python + dados abertos, nada pago)
- Sem dados individuais de contadores (RGPD)
- Máximo 5-6 h por semana

Passos: 1) descarregar dados 2) limpar 3) previsão simples 4) melhorar
- No Windows/Git Bash usa 'py' para correr Python (o comando 'python' não existe)
